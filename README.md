# Bike Service Management System

A full-stack web application that simplifies vehicle service booking and management. The system allows customers to register vehicles, book services, track service status, and view booking history. Mechanics can manage assigned service requests, while administrators oversee users, service centers, mechanics, services, and bookings.

## 🚀 Features

### Customer
- User Registration & Login (JWT Authentication)
- Add and Manage Vehicles
- Book Vehicle Services
- View Booking History
- Track Service Status
- Manage Profile

### Mechanic
- Login
- View Assigned Service Requests
- Update Service Status
- Add Repair Notes
- View Completed Services

### Admin
- Dashboard
- Manage Customers
- Manage Mechanics
- Manage Service Centers
- Manage Services
- Assign Mechanics to Bookings
- View All Bookings
- Generate Reports
